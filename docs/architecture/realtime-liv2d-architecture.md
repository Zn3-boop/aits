# Live2D 实时驱动架构

## 架构分层

```
┌─────────────────────────────────────────────────────────────┐
│                        前端应用                              │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐    ┌─────────────────┐                │
│  │   MediaPipe     │    │   Ollama LLM    │                │
│  │  Face Mesh      │    │  (情绪分析)      │                │
│  │  (468 点)       │    │                 │                │
│  └────────┬────────┘    └────────┬────────┘                │
│           │                      │                            │
│           ▼                      ▼                            │
│  ┌─────────────────────────────────────┐                    │
│  │        情绪/动作决策引擎              │                    │
│  │  - 实时参数层：嘴型、眼动、头部        │                    │
│  │  - 情绪动作层：害羞、调侃、兴奋等       │                    │
│  └────────────────────┬────────────────┘                    │
│                       │                                     │
│                       ▼                                     │
│  ┌─────────────────────────────────────┐                    │
│  │         Live2D 模型渲染              │                    │
│  │  - 五官参数驱动                       │                    │
│  │  - 动作组触发                         │                    │
│  │  - 表情预设切换                       │                    │
│  └─────────────────────────────────────┘                    │
└─────────────────────────────────────────────────────────────┘
```

## 数据流

### 1. 实时驱动层 (MediaPipe Face Mesh)
| 功能 | 输入 | 输出 | 频率 |
|------|------|------|------|
| 嘴型驱动 | 468个面部特征点 | ParamMouthOpenY | 每帧 (~30fps) |
| 眼部驱动 | 眼睛开合度 | ParamEyeLOpen, ParamEyeROpen | 每帧 |
| 头部追踪 | 面部中心位置 | ParamAngleX, ParamAngleY | 每帧 |

### 2. 情绪分析层 (Ollama LLM)
| 功能 | 输入 | 输出 | 频率 |
|------|------|------|------|
| 截图分析 | Canvas截图 + 对话上下文 | 情绪标签 (playful, concerned, excited...) | 每5-10秒 |
| 动作触发 | 情绪标签 | 触发特定动作组 (歪头、挥手、捂脸等) | 按需 |

## 情绪标签 → Live2D 动作映射

| LLM 情绪标签 | Live2D 动作组 | 说明 |
|--------------|--------------|------|
| playful | 歪头笑 | 调皮地歪头微笑 |
| concerned | 担忧表情 | 皱眉、嘴巴微微张开 |
| excited | 兴奋跳跃 | 双手举起、眼睛发光 |
| shy | 害羞捂脸 | 用手遮脸、脸红 |
| confused | 困惑歪头 | 歪头、手指太阳穴 |
| bored | 犯困眨眼 | 慢慢眨眼、头微垂 |
| confident | 自信挺胸 | 抬头挺胸、微笑 |
